# Station

Installers and the update feed for Station, a Windows workspace for running
Claude Code agents: terminals, browser panels, a board and parallel agents in
their own git worktrees, in one window.

Download the latest `Station-Setup-<version>.exe` from
[Releases](https://github.com/kcorrai/station-releases/releases/latest).
Installed copies update themselves from here.

This repository holds release files only; Station's source code is not public.
